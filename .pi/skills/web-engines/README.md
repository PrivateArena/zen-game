# Web engine skills

Eight Agent Skills for browser games: Phaser 4.2 core, Arcade Physics, the tactical grid/board
and text/HUD skills, PixiJS 8.22 rendering, and three.js r186 scene, glTF, material, and
lighting workflows.

Each subdirectory is one skill. Existing projects keep their locked dependency
versions; see [`VERSION-SUPPORT.md`](../../docs/VERSION-SUPPORT.md).

See [`docs/SKILL-FORMAT.md`](../../docs/SKILL-FORMAT.md) for the authoring standard.
